# Словарь данных

## Исходный слой `raw.transactions`

Все поля импортируются как `text`, чтобы ошибки формата не терялись во время загрузки.

| Поле | Поле CSV | Смысл | Преобразование |
|---|---|---|---|
| `transaction_no` | `TransactionNo` | номер транзакции | сохраняется как текст; отмены могут начинаться с `C` |
| `transaction_date` | `Date` | дата операции | `TO_DATE(..., 'MM/DD/YYYY')` |
| `product_no` | `ProductNo` | код товара | сохраняется как текст |
| `product_name` | `ProductName` | наименование товара | сохраняется как текст |
| `price` | `Price` | цена единицы в фунтах стерлингов | преобразуется в `numeric` |
| `quantity` | `Quantity` | количество единиц | преобразуется в `bigint`; отрицательное значение трактуется как возврат |
| `customer_no` | `CustomerNo` | идентификатор клиента | преобразуется в `bigint`; пустое/`NA` заменяется на `-1` |
| `country` | `Country` | страна клиента | сохраняется как текст |

## Очищенный слой `clean.transactions`

Добавляется поле `total_amount = price × quantity`. Полностью одинаковые исходные строки удаляются, затем одинаковые товарные позиции группируются, а их количество суммируется.

## Аналитический слой

| Представление | Содержание |
|---|---|
| `analytics.sales` | операции с `quantity > 0` |
| `analytics.returns` | операции с `quantity < 0`; `return_amount` хранится положительным |
| `analytics.orders` | одна строка на заказ с суммой, количеством и числом товарных строк |
